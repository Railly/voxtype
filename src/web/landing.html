How it works

cli

One command

Type text, get SVG. Pipe to file, stdout, or clipboard. Works with any font on your system.

pure svg

Zero runtime

Output is a single SVG file. No JavaScript, no WebGL, no Canvas. Embeds in any HTML, Figma, or Notion page.

voxel

Rasterize to voxels

Glyphs are rasterized via winding number fill, then converted to isometric voxel blocks with heerich.

plotter

Pen plotter ready

Stroke-only mode with no fills. Export SVG and send directly to your AxiDraw or any pen plotter.

projections

Isometric + oblique

Choose your perspective. Isometric for clean blocks, oblique for dramatic depth.

themes

8 color palettes

From Catppuccin to Dracula to Monochrome. Each theme defines top, front, and side face colors.
